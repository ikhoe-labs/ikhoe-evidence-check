# Security

## Scope
This repository is a public product surface. It must contain only public-facing product assets and non-sensitive configuration.

Private implementation, credentials, tokens, customer data, internal infrastructure details, and proprietary algorithms must remain outside this repository.

## Reporting
Do not publish suspected secrets or vulnerabilities in public issues. Report them privately to the repository maintainers.

## Disclosure rule
A finding is treated as a security incident only after verification. Public documentation is reviewed for unnecessary exposure of secrets, credentials, private endpoints, internal architecture, customer data, and operational access paths.
