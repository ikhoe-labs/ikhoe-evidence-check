# Public assets

This directory contains only assets intentionally published with the IKHOE Evidence Check website.

## Structure

- `brand/` — approved IKHOE brand marks, favicon, and logo variants.
- `backgrounds/` — approved website background imagery.
- `product/` — Evidence Check product visuals and banners.
- `social/` — Open Graph and social-sharing imagery.

## Naming

Use descriptive lowercase names with hyphens. Keep source/original design files outside the public directory unless they are intentionally public.

Brand assets must be reviewed before use so the IKHOE visual identity remains consistent across products.
