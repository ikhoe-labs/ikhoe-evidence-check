# Public IP & Security Boundary

**Status:** Public product boundary
**Date:** 2026-09-07

This repository is intentionally public and contains the narrow Evidence Check product surface. Public availability does not imply that the broader IKHOE architecture, proprietary methodology, internal automation, private prompts, hidden scoring rules, private infrastructure or commercial strategy are public.

## Public boundary

Only material deliberately classified for publication belongs here.

Do not commit:

- secrets, tokens or private keys;
- `.env` files or private configuration;
- private/customer data;
- internal source code from private repositories;
- proprietary algorithms or hidden scoring recipes;
- private prompts or internal agent instructions;
- confidential commercial strategy.

## IP discipline

Original source and documentation remain subject to their applicable ownership and licensing terms. Third-party dependencies remain subject to their own licenses. Before publishing a new capability, review whether publication could expose confidential know-how, affect a patent strategy, or incorporate third-party material without appropriate rights.

## Security boundary

A public repository is not a security control by itself. Runtime authentication, authorization, secret management, dependency security and deployment controls must be verified separately.

## Product claim boundary

`implemented != functioning != connected != executed != evidenced`

Public documentation must not claim broader IKHOE capabilities merely because related private architecture exists.

This document is an engineering/product control and is not jurisdiction-specific legal advice.
